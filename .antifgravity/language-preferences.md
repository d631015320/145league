# 语言偏好设置

## 回复语言
- 所有回答和回复必须使用**中文**
- 解释、说明、总结都用中文
- 错误分析和解决方案用中文

## 代码注释
- 所有代码注释必须使用**中文**
- 包括：函数注释、行内注释、文档字符串、JSDoc 等
- Git commit 信息使用中文

## 文档
- 创建的 Markdown 文档使用中文
- Spec 文件（requirements.md、design.md、tasks.md）使用中文
- README 和 CHANGELOG 使用中文

## 例外情况
- 变量名、函数名、类名保持英文（遵循编程规范）
- 第三方库的专有名词可保持英文
- 错误信息如果是系统生成的可保持原样
- console.log 调试信息可用英文
