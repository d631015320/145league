# 代码质量规范

## 代码风格
- 使用 2 空格缩进
- 字符串使用单引号
- 语句末尾不加分号（遵循项目现有风格）
- 每行最大 100 字符

## ESLint 规则
- 修复所有 ESLint 错误后再提交
- 不允许未使用的变量（用 `_` 前缀标记有意忽略的变量）
- 不允许 `console.log`（调试完成后删除）

## React 最佳实践
- 避免在渲染中创建新对象/函数（使用 useMemo/useCallback）
- 条件渲染使用 && 或三元运算符
- 列表渲染必须有唯一 key
- useEffect 依赖数组要完整

## 性能优化
- 大列表使用虚拟滚动
- 图片使用懒加载
- 避免不必要的重渲染
- 合理使用 React.memo

## 错误处理
- API 调用必须有 try-catch
- 显示用户友好的错误信息
- 记录错误日志便于调试

## 测试要求
- 新功能需要编写测试
- 测试文件放在 `__tests__` 目录
- 使用 Vitest 运行测试
- 测试命令: `npm test`
