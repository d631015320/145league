# 工作流偏好

## 任务执行
- 一次只执行一个任务，完成后等待确认
- 修改代码前先理解现有代码结构
- 大改动前先说明方案，获得确认后再执行

## 测试验证
- 代码修改后运行测试验证
- 使用 `npm test` 运行所有测试
- 使用 `npm run lint` 检查代码规范
- 重要功能可用 Playwright MCP 进行浏览器测试

## 文件操作
- 删除文件前确认没有其他地方引用
- 移动文件后更新所有 import 路径
- 创建新文件时遵循现有目录结构

## 沟通风格
- 简洁直接，不要冗长解释
- 完成任务后简短总结
- 遇到问题时说明原因和解决方案
- 不确定时主动询问

## 回复格式
- 代码块使用正确的语言标记
- 重要信息用粗体或列表突出
- 避免过长的回复，分步骤说明
